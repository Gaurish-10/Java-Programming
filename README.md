# ☕ Java Programming

A organized collection of Java programs, course exercises, and practical implementations covering core object-oriented programming (OOP) concepts, exception handling, and database connectivity.

---

## 📌 Topics Covered

* **Core Java & Syntax:** Basic structures, control flow, methods, and classes.
* **Custom & Built-in Exceptions:** Implementation of custom exceptions (`InvalidAgeException`, `NegativeAgeException`, `StringException`) along with standard `try-catch-throw` mechanisms.
* **Database Connectivity (JDBC):** Integrating Java applications with databases using `JDBCDemo` and handling DML operations via `DMLDemo`.
* **Object-Oriented Design:** Practical case studies including banking systems (`BankingSystem.java`) and age verification routines (`AgeCheck.java`).
